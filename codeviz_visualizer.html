Layer 1: Frontend

TraceProcessor.ts

Receives raw JSON. Reconstructs temporal sequence and resolves pointer addresses.

ExecutionCanvas.tsx

Declarative rendering engine for variables, stacks, and complex aliasing graphs.

Layer 2: Controller

ToolchainService.js

Locates LLVM-MinGW. Manages include paths for trace.h and manages compilation flags.

backendSpawner.ts

Spawns the instrumented binary. Captures stdout and pipes real-time trace tokens to the frontend.

Layer 3: Core Engine

CodeInstrumenter.js

The regex brain. Injects __trace_assign and __trace_scope_enter into the source code.

StructureBuilder.js

Static analysis phase. Maps loops and conditions to a hierarchy used during runtime tracking.

Layer 4: Native Layer

trace_runtime.h

C-compatible interface. Uses __auto_type to safely capture any variable type during assignment.

trace_runtime.cpp

Internal tracking logic. Maintains the runtime scope stack and handles JSON serialization.
